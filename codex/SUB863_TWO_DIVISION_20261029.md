`{MAD, XOR, AND, OR, DIV, REM, CDIV}` 顺序已被排除。它不证明全局最优。

九个输入和目标沿用 `search_early_boundary863.py`：

```text
e, z, u, v, b, prior, a, a_shr19, a_xor_c1
Y = 4097 * (e XOR (e >> 16) XOR N) + C0  (mod 2^32)
N = 0x12345678 XOR C5
```

每个 32 位 b 都有合法树及输入见证。Y 是 b 的全 32 位排列。需要对所有合法
输入正确的固定局部宏，在这个允许的根值上失败，便不能作为所述宏的通用改写。
根值条件分支、额外自由输入及更大的改写窗口不在这一结论内。

## 任意有界中间结果也救不了最后一条乘加或位运算

`audit_conservative_tail863.py` 不限制中间结果 q 的算法，只要求
`0 <= q(b) <= N_i(b)`，其中 N_i 是九个输入之一。随后一条 MAD/XOR/AND/OR
不能得到 Y。

对七个排列输入，取 N_i=0、1；其余两个输入取不同 b 的两个零点。q 在这些点
只可能为 0 或 1。逐项检查最后一条指令：

- `G*I+q` 在零点钉住 `G*I0=Y0`；在第二点枚举 q 的所有值，并求完整 32 位
  线性同余交集。所有交集为空，包含偶数 G 和非可逆系数。
- `I*q+H` 在零点钉住 H=Y0；第二点的有限输出均不等于目标。
- `I*J+q`、位运算及含 q 的固定加数形式，在零点直接不符。
- 只读 q 和根常量的尾部若产生全排列，则 q 必须为全排列。q<=排列 N_i
  与有限和相等迫使 q=N_i；余下一条普通运算不能产生目标的跨位依赖。
  两个非排列输入的值域更小，不能容纳 q 的全排列。

这同时覆盖 `0<=q2<=q1<=N_i` 的两步值链：最后只读一个结果时应用上面的引理；
同时读两个结果时，唯一没在零点直接失败的形式是 `q1*q2+H`。第二点的乘积
增量至多为 1，实际目标差不是 0 或 1。913 种规范化尾部连线中有 211 种读取 q。

## 两个独立分子：完整除数范围，不限于小常量

`audit_two_downward_ops863.py` 处理两个结果分别沿不同初始输入下降的情形。
代表性尾部为 `G*F+Q`，只要求 F<=N_h，Q 为另一个初始分子的除法、取余或
向上取整除法。

在 N_h=0 时 F=0，故 Q 必须等于 Y。对 9×9×3=243 个上下文，用精确商区间
和余数整除条件求出整个 `[1,2^32-1]` 除数域内的候选，共 **43 个**，并非
人为限制除数上界。两个非排列分子的第二个零点立即排除其候选。

其余输入在 N_h=1 时，Q 已不等于 Y，故 F 必须为 1，完整 32 位 G 被钉住。
在 N_h=2 时，F 只有 0、1、2 三种值，没有一个符合目标。初始系数、平方及
异或/或的对应形式也在这些见证点失败。乘积加常量的 81 对初始祖先通过各自
零点或 0/1 点排除；平方加初始值使用零点目标不是模 2^32 平方的事实。

初始数据右移的移位量即使来自数据或前商，在固定输入上的输出也仅属于
`{x>>s: s=0..32}`。九个零点上，所有初始数据的完整右移值域都不包含 Y，
因此相同结论适用于两条初始/前值数据的下降运算混用 DIV/REM/CDIV/SHR。
**预备常量作为数据、数据作为移位量的 SHR 不由这个论证覆盖。**

## 除法—普通运算—除法：唯一幸存除数也有显式矛盾

末条 DIV/CDIV 的输出若大于 2^31，必定是除数 1，且输出等于分子。
末条 SHR 若输出大于 2^31，移位量必定为 0，同样等于数据；末条 REM 则永远
不能产生 `2^32-1`。

所以只需在高目标点检查中间普通运算。九个输入的最低位只依赖 b0、b19，
这四个类别内的高目标都有两种奇偶性。中间一条 MAD/位运算的输出位 0
只能是首商位 0 的一元布尔函数，因而首商和目标在同类点之间的奇偶差必须一致。

`audit_high_division_middle863.py` 对九个分子、floor/ceil 共 18 组，使用精确
除数区间逐步求交，从 `[1,2^32-1]` 出发。1,233 条必要约束对应 680 个不同
高目标 b；全部已用合法树及冻结参考核对。结果仅剩 `q=e//65536`，没有 ceil
幸存者，也没有奇数 floor 除数；REM 的奇偶公式因此将其一并排除。

对唯一幸存者，选四个高目标点，其全部初始低 16 位相同：

```text
q:             63985, 21407, 32958,  1859
Y mod 65536:   64218, 62656, 12705, 24716
weights:       32332, 48558, 34928, 15254
```

任意一条中间 MAD 在这些点上都包含于 `A+B*q+C*q*q (mod 65536)` 的放松。
weights 与列 1、q、q² 的内积均为 0，与目标的内积却为 **62384**，给出直接
可验的矛盾。任意中间位运算也不行：第 0、3 点的 q 位 2 相同，Y 位 2 不同，
而其他操作数在该位都为常量。主审计独立重放了 18 组区间及上述数值证书。
