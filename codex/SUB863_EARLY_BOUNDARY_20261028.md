# 九个已有字的三指令边界审计

**可执行最好仍为 864 cycles，没有得到 863 程序。** 本轮读取了更多真实哈希
中间值，并把局部三指令语法扩大到任意固定移位量。结论只约束下面的宏，
不构成整个内核的下界。提交文件和冻结模拟器均未修改。

## 1. 窗口与输入

目标仍是第 10→11 轮根节点边界：

```text
T_N(e) = 4097*(e XOR (e>>16) XOR N)+0x7ed55d16
N = 0x12345678 XOR 0xb55a4f09 = 0xa76e1971
```

当前需要 SHR、XOR、节点 XOR、MAD 四条。三条等价宏若存在，32 个向量名义
节省 256 lane，足以超过维持相同边界时所需的 53 lane；最后仍须实际编译、
准备参数并调度验证。搜索把已有字免费提供给新宏：

```text
u = 33*b + 0xe9f8cc1d
v = 16896*b + 0xaccf6200
z = u XOR v
e = 9*z + 0xfd7046c5

a = (b XOR C1) XOR ((b XOR C1)>>19)
prior = (a-C0)/4097       # uint32 中的奇数逆元乘法
s19 = a>>19
mix = a XOR C1
```

九个输入为 `[e,z,u,v,b,prior,a,s19,mix]`，C1=`0xc761c23c`。四个新输入在真实
原程序中已经计算，但它们不是 b 的 T 函数，不能复用旧的首 MAD 模 4 割点条件。
新的搜索没有使用该条件。256 个随机原始输入与冻结哈希的阶段 trace 对照通过。

每个私有常量可任意依赖根节点。固定一个合法根足以排除需要适用于所有根的
这种宏；所有主输入保留完整 32 位。反例附实际 30 位初值和叶节点的构造，
用冻结 reference 回放，而非仅在扩大定义域上给出反例。u/v 的理想独立视图
给搜索更多自由；物理交错存储不会推翻这里的负面结果。

## 2. 完成的语法范围

至多三条直线指令，操作为 MAD、XOR、AND、OR、固定右移，任意 SSA 连接及
预备常量。ADD、SUB、MUL、固定左移都可等价规范为 MAD。移位量允许任意
uint32 常量，包括 0、31 和 ≥32，常量也可依赖根。

**变量移位量、除法、比较、FLOW、访存和四条以上的窗口不在这个完成范围内。**
本轮另排除了一类变量右移，见第 6 节；没有声称变量移位整体关闭。

## 3. 先做的完整 SMT 搜索

`search_early_boundary863.py` 的默认模式检查“先 SHR16 读取早期字，再接一条
MAD 和一条位运算”，共 74,100 个规范程序：20,700 UNSAT、53,400 最低位
依赖排除，无超时。

`--all-orders` 再允许 MAD 或位运算在前、移位读取新结果。要求确实读取至少
一个新早期字，共 **233,640** 个规范程序。首批 74,100 项复用，新增部分为
55,214 UNSAT、104,326 最低位排除。合并为 75,914 UNSAT、157,726 最低位
排除，无超时。完全不读早期字的范围已由上一轮五字完整审计覆盖。

最低位条件保留真实的 b0、b19 四类。初始字的 bit0 都只依赖这两个位；
目标 bit0 则随 b16 翻转。唯一移位位必须在每类中影响输出。新审计还用
独立的 8 位真值表重查了全部最低位排除，并与 Z3 对照 180 个随机图。

原始搜索文件合计约 94 MB，以 gzip 无损存档。归档元数据保存编码与解码后
SHA256，逐字节往返核对；原始源指纹仍指解码后的内容，没有改写求解结果。

## 4. 任意固定移位量怎样关闭

`close_early_boundary863.py` 组合了几种独立证据：

- **没有 MAD。** 两个实际可达输入在全部九个输入的 bit31 上相同，但目标
  bit31 不同。逐位运算与固定右移的任何有限组合都保留这种不可区分性。
- **没有右移，或唯一右移量 ≤15。** 翻转 b16 不改变全部初始字的低 16 位，
  但必改变目标 bit0。T 运算的任意组合都不能补回这项信息。
- **右移读取已有字。** 九个来源、33 个代表移位量共 297 项，296 项各有两个
  输入：初始 bit0 及移位后 bit0 均相同，目标 bit0 不同。唯一留下 e>>16。
  这项证据与移位前后其他 T 运算的数量无关。
- **位运算先执行，再右移其结果。** 除 16 外的 32 个代表移位量，均有两个
  输入在初始 bit0 和该位置的全部九个输入位上相同，目标 bit0 不同。
  移位量 16 已由完整 SMT 范围关闭。
- **MAD 先执行，再 SHR，最后是位运算。** 若最后读取一个初始字，最高位
  反例适用。若最后是 `t XOR (t>>s)`，反演 g_s 后，把任意一条 MAD 放宽为
  五个基础变量的 21 系数二次多项式。全部 31 个非零有效移位量都不相容，
  保留真正单 MAD 的正控制。AND/OR 自折叠不是置换。
- **SHR 读取已有字，另两条都是 MAD。** 放宽到 b,z,a,s19,mix,q 的 210 系数
  四次整数多项式，九个来源均不相容。实际两条 MAD 的正控制全部保留。

## 5. 两条 MAD 或两次 SHR 的剩余形状

对于 `t=MAD(...); q=t>>s; out=MAD(...)`，0..15 已由低位依赖关闭，≥32
退化为零。对全部九字操作数角色枚举，每个 s=16..31 有 **120,204** 个
规范图。相同证书同时覆盖这 16 个移位量：

| 证书 | 每个移位量的图数 |
|---|---:|
| 最低位依赖不成立 | 67,441 |
| 整数多项式加有界 q 的矩形差分 | 37,989 |
| 目标减去已有加数的像超过 65,536 | 10,206 |
| 输出仅依赖 q，像太小 | 2,268 |
| 置换求和要求 K 偶，而最低位要求 K 奇 | 567 |
| `t+q²` 不保位置换的和 | 567 |
| `q*(v+1)` 要求 q 超过 65,535 | 567 |
| 奇数 `t*q` 的非零残差不能被 65,536 整除 | 405 |
| 真正 t 割点后的函数不单射 | 149 |
| `t+t*q` 不保位置换的和 | 45 |
| 合计 | **120,204** |

矩形反例选择 a 的 bit16、17 自由变化，使十个坐标（九个已有字和 v>>9）
的增量都被 2^16 整除、混合差分为零。任何整数多项式的混合差分模 2^32
因此为零；目标差分距零 **2,027,814,888**，超过有界 q 能贡献的 131,070。

对每个已有加数 h，另找到一个合法输入使 `T_N(e)-h` 非零且被 65,536 整除。
`t*q+h` 的最低位传递又迫使 t 恒奇。模 65,536 反演 t 得 q=0，与非零残差
矛盾。其余像与求和证据均分开保存，不将超时改名 UNSAT。

一条 MAD、两次 SHR 若最后一条是有效固定 SHR，不可能输出完整置换；剩余
形状可放宽为两个已有字各自移位、最后 MAD。枚举 297 个移位字的全部无序
配对及 MAD 角色，检查 **1,725,867** 个最低位必要条件，仅 20 项通过。
它们只使用 e>>16、e>>16 的副本、z、u 或 v>>9，全部由上述矩形或残差像关闭。
连续两次移位合并、死代码与恒等移位的退化也包含于已关闭范围。

## 6. 变量移位新增的一项排除

取 b=`i*65536, i=0..7`。全部九字的低 16 位完全相同，目标低三位却依次为
`4,5,6,7,0,1,2,3`。若程序只有一次数据相关右移，其余操作均为 T 运算，则
这八个状态中至多一个移位量可以 ≥32，否则两个移位结果为零，输出低 16 位
碰撞。九个已有字直接用作移位量时，各有 7 或 8 个状态 ≥32，所以全都排除。

尚未覆盖的是用新计算结果作为移位量，以及多次向低位传递信息。下一轮应
优先检查这些形状或更大的联合窗口，不再重复此处完成的固定移位三指令语法。
