# 四指令窗口：扩展预备移位量和一般除法

**已验证最好仍为 864 cycles，没有新的 863 程序。** 本轮搜索的是把第 10→11
轮的五条计算替换为四条，免费输入只有八个已有字，不提供 e：

```text
[z,u,v,b,prior,a,a>>19,a XOR C1]
e=9*z+C4
Y=4097*(e XOR(e>>16) XOR N)+C0
N=0x12345678 XOR C5
```

所有运算为完整 uint32；常量可以任意依赖根，但不能依赖 b 或叶节点。
下述结论只适用于明确列出的局部窗口和宏，不构成全内核最优证明。

## 1. 不再固定右移量为 16

`search_prepared_shift_joint863.py` 把唯一的右移量作为未知预备常量一起求解。
其余三条为 MAD/XOR/AND/OR，任意规范 SSA 连接，仍然保留原输入旁路。

翻转 b16 时，全部已有字的低 16 位不变，目标位 0 却翻转。T 运算无法改变
这个事实，因此唯一的预备右移必须在 16..31；小于 16 无法传递所需信息，
至少 32 则结果为零。两个条件分别用完整 32 位 SMT 核对。

本批共 **1,384 个连接**，每项同时允许这 16 个移位量：

- 初查：1,075 SMT UNSAT、284 移位割点排除、25 UNKNOWN。
- 30 秒复查：其中 24 项 UNSAT，剩 1 项。
- 对最后一项补入“任意前缀的 T-only 数据割点”检查后，整项 UNSAT。

最后一项的中间字形如 `P=z*(u XOR K)+B`，后续只依赖 P。因 z 与 u 的低
两位相同，任意 K/B 下 P 的低两位最多有两种结果；它无法作为目标全排列的
数据割点。该证书同时覆盖全部移位量。另按 16..31 拆开的原始运行保留了
7 项 UNSAT、9 项 UNKNOWN；整族的后续证书关闭了这些未定，不改写原始状态。

因此这批连接已全部排除，**不是整个四指令语法的完整枚举**。

## 2. 478 个合法状态给出更强的参数界

选择宽度 9、base=`136315184`，让 b9..b18 遍历，保留目标低九位各不相同的
478 个状态。它们的全部九个早期字（含 e）的低九位分别完全相同，且每个 b
都有实际 30 位初值和合法树，全部通过冻结参考回放。

在只有一次除法或右移、其余都是 T 运算的程序中，前缀的低九位也相同，
后缀只能经由 q 的低九位区分这 478 个目标。于是：

| 唯一的非 T 操作 | 必要条件 |
|---|---|
| `floor(P/D)` | `D <= 4294967295//477 = 9004124` |
| `ceil(P/D)` | `D <= 4294967294//476 = 9023040` |
| `P%D` | `D <= 9004124` |
| 预备右移 | 移位量至多 23，因此有效范围缩到 **16..23** |

floor 的总值域至多 `floor(MASK/D)+1`；ceil 至多 `ceil(MASK/D)+1`。
REM 中 `P_low9` 固定，而 `P%D=P-D*k`，k 至多取 `floor(MASK/D)+1` 个值。
这些都是完整除数域上的必要条件，没有采样除数。计数界不要求前缀只有一条
指令，但要求其余操作为 T，且除数/移位量是同一个预备常量。

## 3. 任意“最多一种高值”的 q，也不能只靠最后一条补回目标

`audit_one_high_tail863.py` 进一步不限制 q 的算法，只要求 q 在全域中至多有
一种不同的值大于 2^31。随后一条 MAD/XOR/AND/OR，读取 q、九个初始字和
根常量，全部 **913 个规范尾部形式**都无法得到 Y。

证据包括：零/奇偶类见证、平方模 4 的像、45 组固定初始乘积的两个不同高残差、
完整非可逆标量同余，以及标量商系数的全域枚举。本轮重新编译并执行后者：
九个加数字分别扫描全部 2^31 个奇数逆元，共 **19,327,352,832** 个参数，
没有一个满足“至多一种高值”的必要条件。每个残差及对应 b 均重新核对，
扫描源指纹和完整记录保存在 `one_high_tail863_full_enum_20261029.json`。

这适用于 q<=2^31 的情形。预备 floor/ceil 的除数 1 不传递新低位信息，
其余除数使 q<=2^31；REM 经上面的信息界也小于 2^31。因此不论前缀有多复杂，
最后若只读 q 和原有字，就已经失败。它不覆盖最后还读取其他新中间值的情况。

## 4. 多项式加商：不限前缀次数的矩形证书

若 `Y=R+q`，P/R 只是已有字上的整数多项式，q 为 P 的预备除法或右移，
已有的四点矩形仍可用于任意多项式次数。所有坐标增量均被 2^16 整除，
坐标混合差分为零，因此任何整数多项式的混合差分模 2^32 为零；目标差分
距离零却为 **2,027,814,888**。

对 floor，写 `P=D*q+r,0<=r<D`，有 `D*Y=D*R+P-r`；ceil 则最后为 `+r`。
D=1..4 时，`D*Delta(Y)` 距离零均超过 `2*(D-1)`，直接矛盾。
D>=5 时，q 至多 858,993,459，差分也不够大。REM 使用第 2 节的 D 界，
右移使用 q<=65535，同样失败。该证书不覆盖位运算前缀、q 的非单位系数，
或多项式部分再次读取 q 的情况。

## 5. 完整除数域的排列和检查

若 P 是真正的数据割点，目标的全 32 位排列要求 P 和最后的单变量映射都为
排列。`audit_quotient_pair863.py` 处理两种尾部：

```text
Y=G*P+op(P,D)       Y=P+G*op(P,D)
```

P 可来自任意长度的 T-only 前缀，G/D 为预备常量。这里没有额外初始字加数或
运行时系数。令 M=2^32，排列的元素和模 M 必为 M/2。将除数按商不变的区间
分组，并逐区间解完整线性同余，覆盖全部 M-1 个非零除数，得到：

| 商的和 | 和为 0 的 D | 和为 M/2 的 D |
|---|---|---|
| floor | 无 | `1,2,4,...,2^31` |
| ceil | `2,M-2` | `1,M/2-1` |

floor 使用 131,071 个精确区间，ceil 使用 131,070 个。公式为
`sum_floor = K*M-D*K*(K+1)/2, K=floor(M/D)`，
`sum_ceil = (K+1)*(M-1)-D*K*(K+1)/2, K=floor((M-1)/D)`。
单个区间上都是关于 D 的线性同余，包含非可逆系数。

对 `P+G*floor`，传递目标位 0 迫使 G 为奇数，排列和却要求 floor 的和为零，
故不可能。对 `G*P+floor`，和条件留下偶 G、幂次 D。令 Q=M/D，将输出乘以
`(G*D+1)^-1` 后，各余数对应一个长 Q 的区间。完整无重叠覆盖要求区间起点
都在 Q 的网格上，故 `G=Q*t` 且 t 奇，输出位 log2(Q) 等于 P 位 0。
真实目标的每一位都有“初始位 0 全相同、目标位不同”的合法对，因而矛盾。

ceil 的和条件加上第 2 节上界，只剩 D=2。两个半区间覆盖强制 G=M/2-1。
两种尾部各要求 `P0=indicator(0<Y<=M/2)` 或 `P0=Y0 XOR Y31`，均有合法
反例。REM 则由奇除数、排列在 2 的幂次模数上的均匀计数、以及 floor 和为零
不可能的事实关闭。详细论证和见证保存在 `quotient_pair863_audit.json`。

这关闭整个指定双字尾部族，但不关闭一般四指令语法。

## 6. 一般除法搜索仍有未定

另对 528 个四指令连接允许完整预备 DIV/REM/CDIV。使用上述证书和两种精确
编码后，合并状态为：

| 最终状态 | 连接数 |
|---|---:|
| SMT UNSAT | 242 |
| 除法形成真割点，像太小 | 126 |
| 任意 one-high q 的尾部证书 | 27 |
| 多项式加商证书 | 6 |
| **仍为 UNKNOWN** | **127** |

没有 SAT 等价候选。对最后 127 个，另尝试 D=65535、65537，共 254 个具体
分支，144 个 UNSAT、110 个 UNKNOWN。这个有限除数实验**不关闭**127 个
完整除数域的未定连接。

第二种除法编码使用 64 位乘积/余数约束，避免直接把每个符号除法展开为电路。
floor 要求 `q*D<=P<(q+1)*D`；ceil 要求 `(q-1)*D<P<=q*D`，并单列 P=q=0；
REM 要求 `P=k*D+q,0<=q<D`。乘积加一个字不会超过 64 位上界，所有比较为
无符号，ceil 的加法保留进位。即使综合得到模型，仍用原始除法表达式做随机
检查及完整 32 位反例验证。
