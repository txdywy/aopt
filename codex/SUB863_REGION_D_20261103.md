# 区域 D：带右移的 4 指令 C5 中段折叠——纤维归约与穷举（2026-11-03 至 11-04，进行中快照，第 4 版）

`problem.py` 或 `tests/`。本文是**进行中的快照**：已完成部分的结论是确定的；

## 0. 问题与价值

把 C5 折进哈希中段可省 1,279 lane（863 只差 53 lane）。早先的工作把**不含右移**的
4 指令中段全部封死；剩下的**区域 D**：4 条指令、至少一条 `>>`、末条不是 `>>`，
对全部 32 位私有常量与任意输入键 K 实现

    P(z) = F(z ^ K) ^ O,   F(x) = 9*((33x + K1) ^ (16896x + K2)) + C4,

O 取四个可吸收键之一（四者在 bit 15 以下一致，所以只看低 c ≤ 15 位对四个 O 同时成立）。
指令 {MAD, XOR, AND, OR, SHR}，每条指令两个私有常量。只要区域 D 里存在**一个**程序，
就能拿到 1,279 lane。

**范围。** MAD 已含 `+ − ×` 与按常数左移，`%` 取 2 的幂即 AND；本文在此之上加入 `>>`
（常量与运行时移位量，含"常量 >> 运行时"与多条 `>>`）。**仍不在范围内**：运行时移位量的
`<<`、`// % cdiv`（非 2 的幂）、`< ==`、以及额外的 live 输入（如 a、a>>19）。其中运行时 `<<`
模 2^c 只经 min(b, c) 依赖 b，定理 V 的论证（b ≥ c 的点覆盖每个剩余类 ⇒ 化为 3 条 T-op）
同样适用，但逃逸部分没有计算。

| 类别 | 连线数 |
|---|---:|
| 单 SHR、常量移位（SHR 在 I1 / I2 / I3） | 108,750（55,010 / 34,040 / 19,700） |
| 单 SHR、运行时值 >> 运行时移位量 | 212,490 |
| 单 SHR、常量 >> 运行时移位量 | 108,750 |

## 1. 为什么旧方法卡住

直接的 32 位 SAT（`rdg.py`：全部 SHR 操作数 32 位、移位量为自由 32 位字面量，精确）
对大多数连线很快，但对"移位值是 z 的仿射式"一族会卡死：例如
`out = (z·((Az+B)>>s) + Az+B) ^ K`，c=11、12、15 各给 240–400 秒仍超时。
困难的本质是：求解器必须自己"发现"输出是 T 函数（低位只依赖低位）这一事实，
而这需要对 A 的高位与 z 的高位联合推理。

## 2. 纤维归约（本轮新方法）

固定 z 的模 2^c 剩余类 z0，纤维 z = z0 + 2^c·y 上所有 T-op 值模 2^c 不变，只有移位
结果变化；输出模 2^c 必须对整条纤维等于 τ(z0)。因此只要能**精确刻画移位结果在纤维上
可取的值**，问题就变成纯 c 位的有限问题。

* **仿射移位值**（`rda.py`）：w = A z + B，A = 2^e·A1（A1 奇）。纤维上
  w = B_lo + 2^e·m(z0) + 2^(c+e)·h，m = (A1 z0 + B_h) mod 2^min(c, 32−e)，
  而 h **取遍** [0, 2^(32−c−e))。令 δ = s − e：
  - δ ≥ c：u 模 2^c 取遍 [0, 2^min(c,32−s))，含 0 ⇒ 化为 ≤3 条 T-op ⇒ 与 closure3 矛盾；
  - δ ≤ 0：u = (A'z + B') mod 2^(32−s)，且 w ≡ (u<<s) + (B mod 2^s)；
  - 1 ≤ δ ≤ c−1：u = (m' >> δ) | (r << (c−δ))，r 取遍 [0, 2^min(δ, 32−c−e))。
  三种情形各是一个 c 位 CEGIS 查询，对一切 s 与一切 32 位常量精确。
* **按位路径**（`rda2.py`）：(x op k) >> s = (x>>s) op (k>>s)，所以 w 经 XOR/AND/OR
  常量后再移位同样精确；k>>s 用与 k 低位绑定的新符号表示。
* **仿射移位量**（`rdvf.py`）：b = A_b z + B_b。v2(A_b) ≤ 31−c 时每个剩余类都有
  b ≥ 2^c 的点，u = 0 ⇒ closure3 矛盾（无需搜索）；否则 b 在纤维上恒定，
  值的高位仍按上式自由。也覆盖"常量 >> 运行时"。
* **按位移位量**（`rdvf2.py`）：b = G(w_b)，G 为与常量的按位组合。按位运算逐位作用，
  所以 b 在第 c+e 位以上是 G 作用在自由 h 上；若 (G(0)|G(~0)) 在这些位非零，
  每个剩余类都有 b ≥ 2^c 的点 ⇒ u=0 ⇒ closure3；否则 b 在纤维上恒定，照常搜索。
* **二次值**（`rdp.py`，**未完成验证，未用于任何结论**）：v = a2 z² + a1 z + a0。逐类 d = v2(2a2·z0 + a1 mod 2^c)；
  d < c 时纤维上 v = (V0 mod 2^(c+d)) + 2^(c+d)·h，h 取遍；d ≥ c 时用显式 y（精确）。
* **一般多项式值**（`rdp2.py`，SHR@I3 的二次–四次值）：c ≥ 11 时 3c ≥ 32，所以对任意次数
  v(z0+2^c y) = V0 + 2^c·y·v'(z0) + 2^(2c)·y²·v''(z0)/2（mod 2^32）；逐类 d = v2(v'(z0) mod 2^c) < c 时
  高于 c+d 位取遍，否则用显式 y。系数 a_i 每个查询只算一次，逐样本只有常数乘法。
  **逃逸过滤**（对任何单 SHR 连线都成立）：若每个剩余类的纤维上都有一点使 u = 0，则 u := 0 的
  ≤3 条 T-op 程序在每个类上等于目标，与 closure3 矛盾；所以只需搜索"某个类 z* 上 u 永不为 0"的常量。
  对 z* 加必要条件（自由形：c+d > s 且 (V0 mod 2^(c+d)) ≥ 2^s；显式形：V0 ≥ 2^s）。
  配合 c = 13，SHR@I3 最难的二次值连线全移位一次查询 38 秒 UNSAT（c = 11 不加过滤时 s = 20–23 超时）。
* **平方路径**（`rdq.py`、`rdvq.py`）：w² + w 的导数 2w+1 为奇，纤维映射是双射，
  高位仍取遍；作移位量的 w² + k 用精确展开
  (B_lo + 2^e m + 2^(c+e)H)² = B_lo² + 2^(e+1)B_lo·m + 2^(2e)m² + 2^(c+e+1)·T·H + 2^(2c+2e)H²，
  逐样本只剩 c 位乘法；按 e 逐个拆成独立查询（移位全为常数）。

效果：上面那个 400 秒超时的结构 1.9 秒 UNSAT；pos=1/pos=2 的 204 个仿射残余
全部 UNSAT（均值 2.2 秒，最长 21 秒）；38 个按位路径残余、5 个平方路径残余全部 UNSAT。

**证明要点。**

1. *纤维引理。* T-op 的低 c 位只依赖输入的低 c 位，所以纤维上一切 T-op 值模 2^c
   固定；输出模 2^c = H(z0, u mod 2^c)，H 由其余三条 T-op 决定。目标 τ 是 T 函数，
   因此 H(z0, w) ≡ τ(z0) 对纤维上 u 可取的每个值 w 都成立；反之若对每个 (z0, w)
   成立，原程序在全部 32 位 z 上成立。归约是**等价**而不只是必要条件。
2. *高位取遍。* w = A z + B，A = 2^e·A1：w(z0 + 2^c y) = w(z0) + 2^(c+e)·A1·y，
   A1 奇，所以 y ↦ 高位是 Z/2^(32−c−e) 上的双射。w² + w 时增量为
   2^(c+e)·A1·y·(2T+1) + 2^(2c+2e)·A1²·y²，线性项系数奇、二次项系数偶，仍是双射。
   二次 v 一般地：增量 = 2^c·y·D + 2^(2c)·a2·y²；D 的 2-进赋值 d < c 时同理。
3. *u = 0 ⇒ closure3。* 把 u 换成常量 0 后，每条读 u 的指令退化为 T-op 或常量
   （MAD(0,b,c)=c、MAD(a,b,0)=ab、XOR(0,b)=b、AND(0,b)=0、OR(0,b)=b），程序落在
   "≤3 条 T-op"空间内；若每个剩余类都有一点 u=0，则该程序在模 2^11 下处处等于 τ，
   与 closure3 矛盾。只有 C0、V、rdvf/rdvf2 分支 (i)、rdq 情形 A 用到这一步（需 c ≥ 11）；
   rda 的 δ ≥ c 情形直接带着自由 u 计算，不依赖 closure3。
   *情形 2 捷径*（纯仿射路径）：s ∈ [11, 21] 时 u ≡ A'z + B'（mod 2^11）是 z 的一条 MAD，
   而 w = 2^s·u + (B mod 2^s) ≡ 常量（mod 2^11），计算 w 的指令及只依赖 w 的值全部变成
   常量，程序化为 ≤3 条 T-op ⇒ closure3。若 w 由某条指令算出且 SHR 是它唯一的使用者，
   该指令在 u 换成 MAD 后成为死指令，对一切 s ≤ 21 同样化为 ≤3 条 T-op。所以情形 2 只需搜索
   s ∈ [0,10] ∪ [22,31]（w 另有使用者）或 s ∈ [22,31]（否则）。
   *多项式证书*：若输出锥里除 SHR 外全是 MAD（末条可为与私有常量的 XOR），情形 2（s ≤ 21）下
   输出模 2^11 是 z 的整数多项式（再异或常量）；`SUB863_FLOW_ENCODING` 的无进位矩形证书
   （`free_keys863_bypass_polynomial.json`：低 11 位全部 4,194,304 对 (I,O) 均被排除，仿射正控例保留）
   表明 F(x^I)^O 不是任何整数多项式，所以这时情形 2 也只需搜索 s ∈ [22,31]；
   这把 SHR@I2 的 `MAD,>>,MAD,^` 一族从超时变成约 30 秒 UNSAT。按位路径不适用（u 多一条按位运算）。
4. *移位量 ≥ 32。* 模拟器的 `>>` 是 Python 整数右移，移位量 ≥ 32 时结果为 0（不取模 32），
   所有模型都按此实现；s = 32 代表一切 s ≥ 32，s = 0 为恒等。
5. *四个 O。* 四个可吸收键在 bit 15 以下一致，c ≤ 15 的结论对四者同时成立。

**多 SHR 同根**（`rdm.py`）：若所有 SHR 的操作数都由同一个仿射值 w 经 SHR、与常量的按位运算得到
（或为常量），则纤维上它们全部是 w32 = B_lo + 2^e m + 2^(c+e) h 的函数，逐样本在 32 位上精确求值、
没有乘法。验证：正控例 5/5，10 个已知 c=8 多 SHR 真解全部复现；cc 残余 `t0>>s1, t0>>s2` 一条
28 秒 UNSAT（固定字面量法 1,581 秒仍超时）。

**输入异或吸收**（`xor_reduce.py`）：若 I1 = z XOR k 且后续指令不再直接读 z，令 z' = z ^ k，
则程序只读 z'，而 F(z ^ K) ^ D = F(z' ^ (k ^ K)) ^ D 形式不变（K 自由）；所以该连线与"去掉 I1、
其余下标前移、末尾补一条 XOR 0"的连线（SHR 位置前移一位）等价。SHR@I3 有 460 条连线如此化到
已全部封死的 SHR@I2 连线；逐条以 40 组随机常量数值核对映射（0 处不符，`test_xor_reduce.py`）。

## 5. 开放与代价

SHR@I3 的移位值若是 z 的**偶导数二次式**（如 (Az+B)²+k、z·(Az+B)+k），纤维上各剩余类的
2-进赋值 v2(v'(z0)) 随 z0 变化：多数类上 u 取遍、少数类（w(z0) 高度可被 2 整除）上 u 被钉住。
逃逸过滤对这一族不起作用（总有类被钉住）；rdp2（c=13）、rdqk（按 e 拆分的精确展开，已验证：
恒等式 20,000 次、正控例 5/5、3 个已知 c=8 真解复现）都能逐个封死，但最难的单条要数百秒
（例：`t0·t0 + k` 一条 815 秒，22 个 e 段中 2 段超时）。按此估计全族需数百 CPU 小时，
本轮只能部分完成；未完成的连线如实列为开放，**不当作已排除**。
