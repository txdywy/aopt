# 计算除数三指令语法：有限分支、精确反推与旁路碰撞

**最好可执行成绩仍为 864 cycles，没有得到 863 程序。** 本轮研究代码和证据
关闭了上一轮计算除数方向的剩余尾部。提交内核、独立 864/865 版本和冻结评测
文件均未修改。这是一个指定边界的局部语法结论，不是全内核最优性证明。

## 范围

沿用 `SUB863_COMPUTED_DIVISION_20261028.md` 的九个免费已有字：

```text
V=[e,z,u,v,b,prior,a,s19,mix]
Y=4097*(e XOR(e>>16) XOR N)+C0 (uint32)
raw_root=0x12345678, N=0xa76e1971
T=MAD/XOR/AND/OR
P=一条 T(V,根预备常量)
q=DIV/REM/CDIV(V_i,P) 或 DIV/REM/CDIV(C_prepared,P)
Y=一条 T(V,P,q,根预备常量)
```

常量允许任意完整 32 位取值；P 必须在所有合法输入上非零。所有 b 都有合法
30 位树值/初始值构造。固定一个允许的根后无解，足以排除统一适用于所有根的
这类三指令宏，但不排除根分支、不同边界或其他算法。

最终运算清单包含 **1,158 个规范连接**，其中 **248 个使用 q**，另外 910 个
用 b16 奇偶不变性排除。清单包含 q 重用、P 重用、两个私有常量和初始字旁路；
还单独处理位运算相同操作数、恒定 P、恒等 P 与 P/P。

## 1. 初始分子：把无界常量变为精确有限分支

对七个双射分子构造 n=0..128 的合法输入；v、s19 则用零分子子空间。
当 P>n 时，三种操作分别给 q=0、1、n（n=0 时全为 0）。

对于 `P+G*q` 和 `G*P+q`，如果所有选中输入都在 P>n 分支，那么目标必须落在
五基础字的 21 系数二次多项式放宽中。该条件不成立。单条位运算的对应默认
分支，另用逐位常量提升和精确位运算插值排除；提升达到上限时仍按 open 处理。
本轮实际关闭的分支没有把上限或超时当作无解。

因此至少有一个选中输入满足 1≤P≤n。逐个枚举这些小 P，方程就把 G 限为
完整的模 2^32 同余根。对每个 G，其他没有小 P 匹配的输入必须回到默认分支，
从而可继续做多项式与位运算检查。`G*P+q` 允许偶数或零 G，使用准确的低位
同余约束，不把非单位乘数取逆。

**九来源 × 三种除法 × 两种尾部共 54 项全部关闭。** 共检查 253,551 个按
来源/操作/尾部分开的有限 G 候选；这不是把 G 的取值人为限制在小范围。

另一个证据文件关闭：

| 尾部 | 项数 | 方法 |
|---|---:|---|
| `初始字*P+q` | 243 | 小 P 精确检查；其余输入强制乘积；加权二次多项式与部分位约束 |
| `P²+q` | 27 | 小 P 精确检查；其余必须是模 2^32 平方剩余 |
| `G*初始字+q` 或 `H+q` | 90 | 枚举 0≤q≤n，以幂次同余类覆盖所有 G/H，三种除法一起处理 |
| `初始字*初始字+q` | 405 | 必需的 q 超过合法分子 n，单点反例 |

位运算尾部也补齐：零分子排除 `q op 初始字`；`q AND P≤n` 给直接范围反例；
`q OR P` 不能输出零；REM 满足 q<P，所以 `q XOR P` 不能输出零。floor/ceil
的 XOR 尾部在小 n、大目标时迫使 P>n，分别钉住 P=Y 与 P=Y XOR 1，均不属于
任何单条 MAD/位运算。只对 q 做预备掩码或仿射变换时，目标双射性要求 q 双射；
对双射分子 n，由 q≤n 和有限域求和可得 q=n，仍无法产生所需 b16 奇偶变化。

## 2. 预备分子：高商与所有 32 位乘数

任意合法 uint32 DIV/REM/CDIV 的结果若 **q>2^31**，必等于其分子。因此同一个
预备 C 不能产生两个不同的高 q。阈值恰等于 2^31 不算高。

- `Y=I*J+q` 的 45 个初始字乘积，各有两个不同的高残差，全部关闭。
- `Y=G*I+q` 中，七个双射 I 取 `h<<16`。这时乘积只读 G 的低 16 位，高 16 位
  在模 2^32 下消失。完整枚举 65,536 个低位，就代表全部 2^32 个 G，包括偶数。
  选取低位标签不同的目标，保证不同输入的 q 不会只是重复同一个高值。
- v、s19 在两个零像上给出不同的高目标，直接排除同一 C。

初次切片关闭 8/9，e 留下 197 个低 16 位参数，原记录保留为 open。随后在全
高半字范围选取另一组输入，**26 个合法点就排除了 e 的全部参数**。独立细化文件
与原文件用 SHA256 绑定，未改写初次搜索历史。

`q XOR 初始字` 同样各有两个不同的高残差；AND 在目标 MASK 处没有可用的 MASK
初始操作数，OR 在目标 0 处没有可用的零初始操作数。只用 P/q/根常量的尾部
则经过非零 P 这一切点，最多有 2^32−1 个输出，不能等于目标的完整双射。

## 3. `Y=I*P+op(C,P)`：精确解出全部除数

I=0 时，目标钉住 `op(C,P0)=Y0`。floor 与 ceil 对应的 C 候选可以**完整**枚举，
七个双射来源合计 1,108 个；v、s19 仍用零像高商证书。

给定 I=n>0、C、Y，写未回绕的输出为 S=Y+t·2^32，0≤t≤n，令
`F(P)=n*P²-S*P+C`。则：

```text
floor: 0 ≤ F(P) < P
ceil: -P < F(P) ≤ 0
```

每项都是两个整数二次区间的差，用 `isqrt` 得到准确端点，并与 1..MASK 相交。
它覆盖全部除数，没有符号除法，也不假定 P 很小。**18 个来源/操作情形的
floor/ceil 全部关闭，甚至无需限制 P 如何计算。**

REM 在商 `k=floor(C/P)` 不变的完整区间上，变成 `(n-k)*P=Y-C (mod2^32)`，
保留所有非单位同余解。五个来源的零像高目标直接钉住 C，随后找到没有任何
合法 P 的输入。剩下 e、a 两个来源另用下一节关闭。

## 4. 奇除数的共同碰撞，关闭最后两个 REM 分支

REM(C,P) 若 P 在某个 b 为偶数，在 b XOR 65536 也为偶数；余数奇偶都等于 C，
乘积旁路的奇偶也不变，而目标奇偶翻转。因此有效的一条 T 除数必须**处处为奇数**。

已有 702 个规范首条连接中，仅 64 个常量奇偶分支满足此条件。若一对输入对
任意这些常量都有相同 P，那么任何 `Y=I*P+f(P)` 必须满足：

```text
Y(b0)-Y(b1) = P(b0)*(I(b0)-I(b1)) (mod2^32)
```

使用已有碰撞，再增加乘积的逐位反求碰撞和强制置一位的碰撞，为 e、a 各
检查 64 个参数分支。**128/128 全部 UNSAT**。只保留见证发现器找到且准确
验证的碰撞，不把发现失败当作无解。

最终汇总又独立回放了 **128 次完整 32 位常量的碰撞查询，以及 128 次旁路
差分方程查询**，全部 UNSAT。54 个不同的见证 b 均重建合法树，并通过冻结
参考内核检查。与前述精确区间及此前的尾部证据合并，完整关闭本报告指定的
计算除数三指令语法。
