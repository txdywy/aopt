# 跨编码常量合并与完整 32 位右移研究

**当前可执行最好成绩仍为 864 cycles。本轮没有生成 863 候选。**
864/865 提交副本、根目录程序、模拟器和冻结测试均保持原样。

本轮不再重复已关闭的中段三条无移位指令搜索，而是检查两个不同范围：
跨越中段边界重新选择全部常量，以及把右移纳入三指令改写。

## 1. 同时调整六个常量，能否吸收 C1 / C5

记所有运算为 uint32，现有四指令中段为

```text
F(x) = 9*((33*x+0xe9f8cc1d) XOR (16896*x+0xaccf6200))+0xfd7046c5
```

搜索新四指令结构

```text
G*((A*x+B) XOR (D*x+E))+H
```

六个常量 A,B,D,E,G,H 全部可变。它比固定原乘数、只改加数更广，但仍只是
“两个并行仿射 MAD、XOR、一个仿射 MAD”这一张图，不涵盖所有四指令程序。

三个目标分别是：

| 目标 | 希望删除的操作 | 若恒等式成立的原图算术收益，未计初始化变化 |
|---|---|---:|
| `F(x XOR C1)` | 首段的固定 C1 XOR | 512 次向量操作，共 4096 lane |
| `F(x) XOR K` | 第 8、9、15 轮的 C5 恢复 | 96 次向量操作，共 768 lane |
| `F(x XOR C1) XOR K` | 在同一段合并两个编码边界 | 对相应轮次同时删除上述两项 |

其中 `C1=0xc761c23c`，`C5=0xb55a4f09`，`K=0xb55afa53`。
末段 `L(e)=e XOR (e>>16)` 在 uint32 下自反且对 XOR 线性，故
`L(e XOR K)=L(e) XOR C5`。这个恒等式有独立完整 32 位 SMT 检查。
因此把 C5 移入上述目标是精确的跨阶段变换，不是忽略输出恢复。

F 是模每个 2 的幂上的置换：33 为奇数，而第二个 XOR 支路的变量部分
左移九位，不改变逐位可逆的对角项；外乘 9 仍可逆。输入、输出 XOR 也可逆。
于是可以安全地缩小常量搜索：

1. G 必须为奇数，否则输出奇偶恒定。
2. A、D 的奇偶必须相反。交换 XOR 两臂后令 A 奇、D 偶。
3. 同时取反两臂不改变 XOR，故可令 B 偶数；对应系数变换为
   `(A,B,D,E) -> (-A,-B-1,-D,-E-1)`。
4. x=0 精确决定 H，不需要搜索第六个独立变量。

这些是函数保持的对称性和必要条件，没有固定 G=9，也没有固定其他原常量。
各运算与低位投影交换，因此低 11/12 位上的样本约束 UNSAT 就足以否定该
完整 32 位结构。搜索期间不计算任何截断后的变量右移。

`search_cross_encoding863.py` 的六项查询全部 **UNSAT**：三个目标分别在
11 位和12 位检查，耗时约 0.10–2.58 秒。具体输入、限制、Z3 版本及结果见
`cross_encoding863_results.json`。

两个未固定参数的正向对照自动发现 SAT，并用独立 Python 计算穷尽全部
2048 个低位输入验证。原 F 的未固定参数对照在 5 秒内仍为 UNKNOWN，原始记录
保留；没有将它改写成通过。测试另穷举全部 4096 个两位六常量组合，检查可逆性
与归一化，并把求解器结果与全部两位置换的独立枚举对照。

结论：这条重新选择常量的路线不能提供所需收益。它没有排除不同的四指令图、
联合改变右移部分、额外前序中间值或查表实现。

## 2. 含右移的三指令中段

`search_middle_shift_orders863.py` 检查一个 MAD、一个逻辑右移、再加
`{+,-,XOR,AND,OR,SHL,SHR,MUL,MAD}` 中一个操作的全部 48 个不同顺序。
允许合法 SSA 操作数选择与任意常量，右移位数也未固定，使用完整 32 位语义。

每次初始求解时限 1.5 秒：**9 个 UNSAT，39 个 UNKNOWN**，没有候选公式。
记录保存在 `middle_shift_orders863_results.json`。这次短时搜索只用于定位范围；
它不能证明其他 39 个顺序不可能。

### 用多项式条件关闭 SHR / MAD / MAD

设第一条右移结果为 q。任意两条 MAD 的最终结果都是 x,q 的总次数不超过四的
整数多项式。允许全部 15 个单项式具有独立系数，是实际两条 MAD 的超集。

对 `q=x>>s`，分别枚举 s=0..31；s>=32 统一以 s=32、q=0 表示。
`screen_shift_middle863.py` 在每个实际完整输入上先精确计算 q，再建立模
`2**32` 的多项式线性同余。**33 个系统全部不相容**，没有求解超时。
模环消元使用 2-adic 赋值最小的主元，允许不可逆系数，并非套用域上的除法。

若位数取输入 x，则在 x>=32 上，`x>>x` 和任意 `K>>x` 都为零。
选取 x=32,40,288,296，F 的低 11 位为

```text
746, 1074, 1002, 306
```

混合差分为 1024。任何整数多项式在这四点的混合差分应被
`(288-32)*(40-32)=2048` 整除，矛盾。

若右移的来源及位数都是常量，q 为常量，后续仍是 x 的多项式，已包含在 q=0
的放宽模型内。这穷尽了第一条右移可使用 x 和任意常量的所有情况。

验证包含每个 s 上的实际正控制程序

```text
q = x >> s
t = x*q + 17
y = t*t + x
```

33 项全部被多项式模型保留；另外检查随机 SSA 操作数组合。独立 SMT 模型也
确认了 s=1,9,19,31 的多项式矛盾。该交叉验证只在完整输入和右移结果已经求出
后投影多项式约束，没有把右移误当成可直接缩短字宽的运算。

因此本轮 48 个顺序的累计状态为 **10 个已排除、38 个未决**。
没有把整套含移位的三指令范围称为最优性证明。

## 3. 对额外输入和准备阶段的补充检查

上一轮的中段三指令排除允许免费使用 p、a、s、mix、b。若仅再允许节点异或前的
状态 v 和选中节点 n，且 p=v XOR n，则任意对所有 v,n 正确的改写也必须在
n=0 时成立。此时 v=p，新操作数仅为原池中的 p 和零，因此仍被原证明排除。
这也适用于以编码节点为 n 的宏：合法完整输入允许该编码节点为零。
该约简只针对这两个额外操作数，不覆盖更早一轮的哈希中间结果或特殊联合输出。

还读取了已验证 864 的未展开 IR，使用现有 `word_ssa.observed` 反向依赖检查。
12 个完整已知常量向量的所有 lane 均被保留；全部 VALU 中也没有只保留部分
输出 lane 的条目。这个保守检查将 STORE 输入等视为观察点，因此只说明没有
在当前依赖模型下发现可直接删除的向量算术，不能排除重写内存布局或常量构造。

当前图的必要边界预算仍为 `51665+52+116`，所以相同首尾开销下到 863 需要
至少省下 53 lane。局部搜索或准备阶段的审计均没有产生这样的可执行新图。
