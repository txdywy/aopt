# 863 新方向：把 C5 吸收进末段或 d9/d10 的首段（2026-10-28）

**可执行最好成绩仍为 864 cycles，本轮没有得到 863 程序。**

## 1. 为什么看 C5

C5（第 5 段的异或常数 0xB55A4F09）在 864 图里大多已经挪到节点上：d0–d8 预异或，共 511 lane。
但还剩三处逐元素的异或，共 768 lane：

- d9、d10 的恢复：节点是逐元素 gather 来的原值，只能在节点异或之后再异或 C5（512 lane）；
- 输出：最后一轮的结果必须精确存回（256 lane）。

此前的笔记只排除了这三处的**单指令**等价形式（`SUB863_FRESH_PASS_20261027.md`）。
本轮问多指令窗口：只要下面任一窗口少一条，就省 256 lane 以上，远超 863 需要的 53。

| 窗口 | 现行 | 问 | 省 |
|---|---|---|---:|
| 一：末段 + C5（第 8、9、15 轮） | `MAD(×9+C4) → >>16 → ^ → ^C5`，4 条 | 3 条精确算出 | 768 |
| 二：d9/d10 首段 | `^C5 → MAD0 → >>19 → ^ → ^C1`，5 条 | 4 条算出 `m·T(u^C5)+c` | 512 |

## 2. 窗口一：末段 + C5，三条指令

目标 `out(a) = L16(9a + C4) ^ C5`，`L16(e) = e ^ (e >> 16)`，a 为中段结果。

两端的免费自由度：

- **输入**：a = p ^ q，q = 512·(33z + C2) 的低 9 位为 0。改 q 的常数可把任意 k < 512 异或进 a；
  加 2^31 翻转第 31 位；p 的 MAD 乘数取 −33 则 a 取反。共 2048 个免费键 K。
- **输出**：在 d9/d10 之前，下一轮的 MAD0 吸收 O ∈ {0, 2^31, 2^32−1, 2^31−1}；最终输出要求 O = 0。
  四个都允许（超集）。

语法为 `grammar3_head863` 的全部 46 种形式、任意 SSA 连线、任意常量（`grammar3_tail_c5_863.py`）。
剪枝与首段相同且都可证明不丢解：每条指令都被使用；必须含非 T 函数（翻转输入第 16 位总会翻转
输出第 0 位）；输出是双射。与首段不同，末条为仿射的模板保留，因为输出必须精确。

| 范围 | 模板 | 结果 |
|---|---:|---|
| 基本操作码 | 6,166 | 6,153 个 UNSAT（K 取任意 32 位，超集）；13 个超时按移位量拆成 416 个情形，K 取 2048 个免费键，全部 UNSAT（最长 41.5 秒） |
| 加 `// % cdiv < ==` | 14,912 | 14,855 个 UNSAT（30 秒，K 取 2048 个免费键；其中 331 个先以任意 K 跑过）；57 个超时：9 个加时后 UNSAT，48 个由下面的 2-adic 规则排除（含 8 个钉住常数后 UNSAT） |

对照：把 C5 换成 0 后，求解器找回自然的三条 `MAD → >>16 → ^`（K = 2^32−1、乘数 −9 的等价形式）。

**除法扩展的超时。** 57 个超时里，5 个以 300 秒重跑后 UNSAT，4 个形状特殊的（710、919、8882、10252）
以 900 秒上限重跑，3–25 秒 UNSAT；其余 48 个都是“`aff(u)` 或 `u ^ K1` → 除法类一元运算 → 组合”。
仿照首段的除法论证（`grammar3_division_valuation863.py`），只把目标的移动阶换掉：翻转输入第 j ≥ 16 位时，e 移动 9·2^j 的奇数倍，所以 `e ^ (e >> 16)` 最低变化位是 j − 16，
目标移动量的 2-adic 阶恰为 j − 16（对任意免费键 K、输出键 O 成立，已抽样核对）。由此（`division_rule`）：

- **偶乘数**：i1 = aff(u) 的乘数为偶数时，翻转 u31 不动 i1、i2，输出移动 2^31 的倍数而非阶 15；
  所以 i1 是 u 的双射。
- **零除数**：除数是 i1（`K // i1`、`K % i1`、`cdiv(K, i1)`），i1 必取到 0，模拟器报错。
- 组合为 A + B·i2 或 X ^ i2。翻转 u16 要求阶 0，故 B 处处为奇数：**B 为 u、u+1、i1、i1+1 时**
  一半输入上为偶数，排除（双射系数）。
- B 为常数时，翻转 u31 要求 i2 的移动阶处处为 15（q = 2^31 // K，r = 2^31 mod K；K > 2^31 时
  三种运算的移动量都不可能处处为阶 15）：`i1 // K` 移动 q 或 q+1（r ≠ 0 时两者都出现，
  其一为奇数；K = 2^k 即基本语法里已排除的右移模板）；`i1 % K` 移动 r 或 r − K（二者阶都为 15
  会迫使 v2(K) ≥ 16，而 2^v2(K) 整除 r）；`cdiv(i1, K)` 只在 K = 2^16 时移动量单一，钉住
  K = 2^16 后交给 z3（7 个，0.4–72 秒 UNSAT）。
- **或位**（3984，`u | K1 → cdiv → K'·i2 + u`）：翻转 K1 已置位的输入位 k 时 i1、i2 不动，输出恰好
  移动 ±2^k。k ≥ 16 时目标的阶是 k − 16；k = 2..15 时，对每个免费键都能构造出阶为 0 的输入
  （让 e 跨过 2^16 进位或借位，28,672 个键×位组合逐一验证），所以 K1 只能是 0..3，四种取值钉住后
  z3 全部 UNSAT。

规则计数：零除数 19、双射系数 14、钉住 cdiv 7、商的阶 4、余数的阶 3、或位 1，共 48。
`grammar3_tail_c5_863.py --audit` 由全部运行记录重算：窗口一的 21,078 个模板**全部排除**。

## 3. 窗口二：d9/d10 首段，四条指令

目标 `P(u) = m·T(u ^ C5) + c`，u 取全部 2^32 个值（节点异或之后的值），m 为奇数，
`T(x) = g19(4097x + C0) ^ C1`。这与第 0 轮的四指令窗口（`grammar4_round0_863`）是同一个问题，
只是定义域换成全 32 位、键换成 C5。语法同第 0 轮（14 种核心形式），全域下再加双射剪枝，
共 12,254 个模板（`grammar4_head_c5_863.py`）。

把输入限制在 u < 2^30 后，这正是根节点取 C5 的第 0 轮问题；所以第 0 轮那些只用到“定义域内的
输入”和目标函数的精确规则，以 C5 为根调用时对本问题仍然成立（在子定义域上找到矛盾即可）。

### 3.1 引理 A：唯一的移位读仿射值

除右移外，核心形式都是 T 函数。只有一次右移 `w >> s` 时，输出第 0 位是 `f(u0, w_s)`；目标第 0 位是
`u0 ^ y19 ^ const`，其中 y = 4097(u ^ C5) + C0。翻转 u19 总会翻转 y19，翻转第 20–31 位从不影响它，
所以对所有 u 有 `w_s = y19 ^ g(u0)`。

设 w = a·u + b，a = 2^d·a'（a' 为奇数）。翻转第 j ≥ 20 位时 w_s 不能变，翻转 u19 时 w_s 必须总变，
由此 s = 19 + d，且 `w_s = bit19(a'u + (b >> d))`。条件化为

```text
bit19(a'u + b') == y19(u) ^ g(u0)      对所有 u < 2^20
```

`grammar4_head_c5_lemma863.c` 对每个 a' 和 g 做半圆弧交集，把 b' 精确求出：**键 C5 无解**；对照键
0、2^31、2^32−1、2^31−1 各有 8 组解（含自然解 a' = 4097）；第 0 轮的根键 0x23542448 也无解。
移位前再与常量做一次 XOR/AND/OR，只会把 w_s 取反或固定，同样被排除。引理 A 一次排除 10,160 个模板。

### 3.2 引理 B：移位只读 u 或 u 的移位

此时输出第 0 位只依赖 u0 和至多三个 u 的单个位；而 u1..u19 中每一位都能在某些 u 上改变 y19，
不可能。再排除 774 个。

### 3.3 求解器、拆分与精确规则

其余 1,320 个模板先交给 z3（CEGIS，30 秒），1,249 个 UNSAT，71 个超时。超时的按移位量拆开，
共 15,168 个情形（58 个单移位模板 × 32，13 个两次移位模板 × 1,024）：

- **单移位（58 个模板）**。s < 19 时移位输入是 T 函数，它的第 s 位与 u19 无关，排除（依赖性）。
  其余情形依次用：
  - **2-adic 阶（全域版）**：翻转第 j ≥ 20 位，目标移动量的 2-adic 阶恰为 j − 19（已证，且抽样核对）。
    移位结果只被最后一条读一次时，最后一条为 A + B·i3 则 j = 20 给出 v2(B) ≤ 1、j = 31 给出
    v2(B) ≥ s − 19，s ≥ 21 不可能；为 X ^ i3、X | i3、X & i3 时 s ≥ 20 不可能。第 0 轮只能用到
    j = 29，界是 23/22；全域上 j 可到 31，界降到 21/20。
  - **刚性位移**：第 0 轮规则 5（`grammar4_round0_bit0_863.rigid_any`）以 C5 为根调用；见证对在
    s = 19..24 都存在。
  - **低位钉住**：读 `aff(xk(u)) = μ(u ^ K) + ν` 的，s = 19 + d（μ = 2^d·奇数），且
    (K mod 2^20, μ 与 ν 的第 d..d+19 位) 是 `xk_affine_solutions(C5)` 的 32 组解之一（自然解在其中），
    再交给 z3。
  - s = 19 余下 4 个情形：两个读 `aff(u | K)`，用第 0 轮的**掩码**规则（`mask_rule_holds(C5)` 成立）；
    两个读 `u + a·(u ^ b)` 与 `u + a·(u | b)`，第 0 轮的 `BF2_C` 对 a、b 的低 20 位全部 2^40 种组合
    穷举，键 C5 下**都无解**（各约 8 分钟）。
- **两次右移（13 个模板）**。
  - 6431（`>>s1 → aff → >>s2 → mad_a(u, i2, i3)`）：第 0 轮的多移位规则以 C5 为根排除 1,010 种组合
    （依赖性 997、耦合 2-adic 阶 7、刚性 6），余下 s1 = 1 的 14 种 z3 立即 UNSAT。
  - 其余 12 个的两次移位都读同一个仿射值 w = aff(u)（并列或嵌套）。同样的翻转论证：较高的读位若高于
    第 19 + d 位，翻转对应输入位只改变它，输出第 0 位就不能依赖它，退回引理 A；若低于，翻转 u19
    不改变任何读数，矛盾。所以较高读位恰是 w 的第 19 + d 位，输出第 0 位是它异或 `G(u0, 较低读位)`，
    化为 20 位上的“两读位”条件（第 0 轮的 G2）

    ```text
    bit19(a'u + b') == y19(u) ^ H(u0, bit_q(a'u + b'))    对所有 u < 2^20，q = 0..18
    ```

    `lemma_a2(q)` 用 z3 逐个 q 求解（每个 1–37 分钟）：键 C5 下 **q = 0..18 全部 UNSAT**；对照键 0 在
    q = 7、12、18 都找到解。

## 4. 结论

- **窗口二全部排除**：在 14 种核心形式、任意连线、任意常量下，没有四条指令能算出 `m·T(u ^ C5) + c`，
  d9/d10 的 C5 恢复省不掉。
- **窗口一全部排除**：基本语法 6,166 个、加除法/取余/比较的 14,912 个，三条指令都算不出精确的
  `L16(9a + C4) ^ C5`，输出和 d9/d10 前的 C5 异或省不掉。
- 两个窗口都没有解，C5 的 768 lane 照旧，**864 不变**。

顺带得到的两条一般结论：

- 引理 A 的 20 位检查只依赖键，几秒一次：四个“仿射兼容”键（0、2^31、2^32−1、2^31−1）各有 8 组解，
  而键 C5、第 0 轮的根键和另外 64 个随机键都无解。对这些键，读仿射值的单移位模板一律失败。
- 全 32 位定义域上，2-adic 阶规则的界从第 0 轮的 s ≥ 23/22 收紧到 s ≥ 21/20。
