# 动态右移量约束与计数尾部闭合

**可执行最好成绩仍为 864，没有 863 程序。** 本轮研究运行时计算右移量的
跨阶段改写，得到一个全局数值范围、一个完整单条计数指令族的闭合，以及三个
最终乘加族的闭合。提交内核、864 独立副本、865 备份、冻结测试和模拟器均未变。
这些结果不证明整个内核最优，也不覆盖完整四指令语法。

## 模型

八个真实存活输入为 `[z,u,v,b,prior,a,a>>19,a XOR C1]`，没有免费提供
`e=9*z+C4`。目标仍是原来的五条指令：生成 e、fold16、根异或和下一次 MAD4097。
固定允许的原始根 `0x12345678`，根字为 `0xa76e1971`。只要在这个合法根上失败，
就不能成为需要支持所有根的等价公式；在这里成功仍须推广、接入和正式计分。

T 指 MAD/XOR/AND/OR，另允许归一化到 MAD 的 ADD/SUB/MUL/常量左移。
本轮全局定理要求**恰有一次 SHR，其余操作全部为 T**；SHR 的分子和计数可由
任意长度 T 前缀生成，所有存活旁路均保留。运行时左移、除法、比较、第二次
右移、其他免费存活字和新的内存布局不在这个定理内。

## 1. 任意长度计数前缀的全局范围

第一步固定 b 的其他位，只变化 b16..18。所有初始字和 T 前缀的 low16 都相同，
目标 low3 却遍历八个值。因此 q low3 必须有八个不同值；至少七个实际计数小于
32，最多一个计数可以让右移结果归零。

写 c=count low16。c<16 时，q low3 最多有五个值（已包括归零分支）；c=30、31
时最多四个、两个；c≥32 时全部归零。因此每个 b 都必须有 **c∈16..29**。

第二步固定 b low9 和 b19 以上的位，变化 b9..18。所有初始字和 T 前缀的 low9
相同。由于 c<512，这次 c 在整个 1,024 点切片上相同。目标 low9 只依赖 b low25，
所以完整检查 512 个 low9 ×64 个 b19..24 签名，覆盖 **33,554,432 个输入**。
全部 32,768 个签名的目标 low9 至少有 **387** 个不同值，最大为 483。

若 c≥24，则 q 的全部取值至多 256 个，与至少 387 个目标低位矛盾。因此：

```text
对每个 b：count low16 ∈16..23，且 q≤65535。
```

这里没有把实际计数截成 16 位。实际计数仍可能是 65536+c 等大数，此时 q=0。
Python、NumPy、Z3 和冻结 ISA 都保留这一行为。准备好的常数分子也不可能：
在每个 low9 切片上 q 只能为 C>>c 或 0，至多两个值。

四个完整 32 位投影性质由 QF_BV 验证。完整数值表 SHA256 为
`5510056a6dfb3eac428e5b96c3e052c84acd39d41bc009fa0c6e814a09791939`。
合法输入/冻结参考回放只用于保存的具体见证，没有把这 3,355 万次模运算枚举
说成同样数量的完整内核执行。

## 2. 单条 T 生成计数：只能退化成常量

先检查 `t=T(initials,root constants); q=numerator>>t`，分子可为八个初始字、
根常量或 t，后续允许任意长的 T 尾部。24 种常量位运算、108 种运行时二元
位运算、420 种规范 MAD 连接，各配十种分子，共 **5,520 个前缀**。

原始结果为 5,470 个最低位必要条件 UNSAT、50 个超时。后者全部为仿射计数；
由可达源值 0/1/8 和全局范围，系数必为 2^16 的倍数。若它非零，计数能落入
16..23 只可能发生在源的一种奇偶类，另一整类 q 恒零，却仍需要复现目标的
b16 奇偶翻转，矛盾。v 使用 `A*v+B=(16896*A)*b+(A*0xACCF6200+B)` 的同一论证。
剩余常量计数与原始分子的组合由 64 对具体见证排除。原始 50 个超时没有改写。

随后加强到**允许任意 T 分子**。对全部 **552 种不同计数形状**，在 34 个八点
切片上要求全局范围、至多一个计数归零，并要求计数在有限探针间变化。
552 个查询全部 UNSAT。另做 552 个独立的完整 32 位查询，任意根参数始终自由，
证明“在这些探针上为常量”必然推出“对所有 b 为常量”。因此单条 T 计算的
合法计数只能是根相关常量，实际值为 16..23。

这 552 个形状与前面的 5,520 个前缀重叠，不能相加当作不同程序数量。
两个或更多 T 生成的计数仍未被这个结论排除。

## 3. 最后乘加同时读取计数和右移结果

令 h 为八个初始字上的任意单条 T，常数参数自由。分子、计数的 T 前缀长度
不限。关闭以下三个族，每族均覆盖 552 种 h 形状：

```text
Y = q*count + h
Y = count*h + q
Y = q*h + count
```

先对前两族做 1,104 个数值范围放宽，得到 910 UNSAT /194 UNKNOWN。
UNKNOWN 保留，随后用独立证书关闭。

对每个 h，找到同一八点切片内的两个不相交四点矩形，使两者都满足：

```text
Δh = h3+h0-h1-h2 = 0 mod2^32，对所有根参数成立
目标 ΔY 的圆周距离 > 3,014,610
```

全部 552 个 h 都找到证书，并逐条用完整 32 位符号根参数回放。MAD 使用初始字
共同 low16 和零混合差分；常量位运算逐位验证对所有掩码的差分；运行时位运算
检查其具体字。两矩形覆盖八点，至多一个计数归零，所以至少一个矩形全部活动，
其实际计数均等于同一 c∈16..23。前两族分别要求 ΔY 的圆周距离不超过
`2*c*65535≤3,014,610` 和 `2*65535=131,070`，均矛盾。

第三族用独立完整枚举。在全部 18 个不同矩形对上，八个目标 low16 都不在
16..23，所以 q=0 的归零分支不可能成立，八点都活动。写 h 的共同 low16 为 H，
目标 low3 的八种取值要求 H 为奇数。对所有 **32,768 个奇数 H ×8 个 c**：

```text
q_i = (Y_i low16-c)*H^-1 mod2^16
h_i = H + 2^16*t_i
q_i*t_i = (Y_i-c-q_i*H)/2^16 mod2^16
```

每个 t_i 的解是一个模 2 的幂的剩余类。矩形 Δh=0 等价于四个解类的有符号和
能为 0，用四个模数的最大公约数精确判断，无需枚举高 16 位。18 个矩形对共
**4,718,592 组参数**，全部无解。

第二套纯 Python 标量实现直接求 `q*h=Y-c mod2^32`，核对 h low16 和矩形，
不使用前一套高半字方程。两套实现逐阶段计数完全一致。它们还通过了有真实解
的自动控制和小字长全部高位赋值对照。三族合计 **1,656 个连接关闭**；这不是
完整四指令图，也不涵盖最终乘加不读取计数的更一般连接。
