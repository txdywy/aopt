# 863 继续搜索：除法扩展与第 0 轮“并入节点异或”的四指令窗口（2026-10-28）

**可执行最好成绩仍为 864 cycles，本轮没有得到 863 程序。**

承接 `SUB863_HEAD_GRAMMAR_20261028.md`。那里留下两件事：除法、取余、比较的扩展只跑了
317/14,777；第 0 轮只搜了三条指令、且输入键只取仿射兼容的 8 个。本轮把两件事都做完。

## 1. 除法、取余、比较扩展

范围同前：全域、4 个仿射兼容输入键、任意奇数仿射输出；在基本语法外加入
`// % cdiv < ==`，新增 14,777 个模板（全部 20,849 个中不含新操作码的 6,072 个已在
前文排除）。

| 阶段 | 处理 | 排除 | 剩余 |
|---|---:|---:|---:|
| z3，10 秒 | 14,777 | 14,560 | 217 超时 |
| 精确论证（见下） | 217 | 69 | 148 |
| z3，120 秒重跑 | 148 | 50 | **98 未定** |

没有任何模板求得解。98 个未定项中 94 个的新操作码在第二条：i1 是 MAD，i2 是
`i1 // K`、`i1 % K`、`cdiv(i1, K)` 或 `K // i1`、`K % i1`、`cdiv(K, i1)`，第三条再组合。
也就是“用常量除法代替右移”。K = 2^19 时它就是右移，已在基本语法中排除。其余 4 个的末条
是两个运行时值相除。

末条两运行时值相除的模板，z3 的除法电路很慢。`grammar3_division_audit863.py`
用以下精确论证处理超时项。设末条 `P = a // b` 或 `P = cdiv(a, b)`：P 必须是全部
2^32 个输入上的双射（m 为奇数，T 为双射），且处处 b ≥ 1（除数为 0 时模拟器抛异常）。
于是 P ≤ a 逐点成立。

- **input-numerator**：a 就是输入 u。P ≤ u 且 P 为双射，从 0 归纳得 P 为恒等，而 T
  不是仿射的。
- **single-source**：a、b 是 i1 与 i2 = g(i1)。P 只经 i1 依赖输入，所以 i1 必须是双射；
  a = i1 时上一条用于 i1，b = i1 时它在某个输入上为 0。
以下三条中，a 是只读 u 的一条指令（i1，或只读 u 的 i2）：

- **injective-a**：a 是奇数乘数的 MAD 或 `u XOR K`，是双射；P ≤ a 迫使 P = a，
  一条仿射或异或指令算不出 T。
- **even-mad-a**：a 是偶数乘数的 MAD，取到 ≥ 2^31 的值至多 2^30 个，而 P 需要
  2^31 个（cdiv 需要 2^31 − 1 个）。
- **small-image**：a 是 `u >> s`（s ≥ 1）、`u & K`（K 非全 1）、平方、移位常量、
  `u // K`、`u % K`、按常量的 cdiv 或比较：大于 2^31 的取值不够；s = 0、K 全 1、
  `u // 1` 等退化情形就是输入本身或常量，已归入前几条。

## 2. 第 0 轮：把节点异或并进首段

### 2.1 问题

第 0 轮先算 `x = v XOR R`（输入值与根节点，均 < 2^30），再进首段，从 v 到中段 F 共
5 条指令。R 只在运行时可知，但内核可以在 setup 里由 R 算出任意常量，F 的 MAD 吸收
任意奇数仿射输出。所以，若存在固定骨架 P（4 条指令、常量可依赖 R）使

```text
P(v) = m·T(v XOR R) + c     对所有 v < 2^30，m 为奇数
```

第 0 轮每元素省一条 VALU，共 256 lane，超过 863 所需的 53。骨架必须对每个根节点值
都成立，因此**只要对一个随机 R 无解，就排除该骨架**。本轮取 R = 0x23542448
（`random.Random(863).randrange(2**30)`）。

这个形式包含“节点异或带任意键、再接三指令首段”（第一条为 `v XOR K`），即上轮在第 0
轮没有覆盖的任意键情形。

### 2.2 语法

`grammar4_round0_863.py`：14 种核心形式（MAD；与常量的 `^ & |`；常量右移；
`K*a+b`、`K*b+a`、`a*b+K`、`a^b`、`a&b`、`a|b`；三操作数 MAD），任意 SSA 连线。
平方、运行时移位量、除法与比较不在其中：它们在三指令搜索里从未起作用，加上后四指令
模板超过一百万个。剪枝同三指令版本（每条指令被使用、含右移、末条不是单操作数 MAD），
另删去“第一条是右移且是 v 的唯一用法”的模板（定义域对 `v XOR 1` 封闭）。共 14,150 个
模板：单移位 12,584 个，两次移位 1,514 个，三次 52 个。

### 2.3 比特 0 引理

除右移外，14 种形式都是 T 函数，结果第 0 位只取决于各操作数的第 0 位。只有一次移位
`w >> s` 时，输出第 0 位因此是 v0 与 `bit_s(w)` 的布尔函数。目标第 0 位是
`v0 ⊕ y19 ⊕ 常数`（m 为奇数），其中 y19 是 `4097·(v⊕R) + C0` 的第 19 位，它不是 v0
的函数。所以必须有

```text
bit_s(w(v)) = y19(v) ⊕ g(v0)     对所有 v < 2^30
```

w 是喂给移位的子程序。这个条件只涉及移位之前至多三条指令，许多模板共用同一个 w，
共 887 种。按 w 的结构分三类：

- **bitwise**（只由 u 经 `^ & |` 构成，含 u 本身）：`bit_s(w)` 只取决于 `v_s`。对每个
  s 给出一对输入，它们在第 0、s、19 位相同而 y19 不同，条件不可能成立。10,525 个模板。
- **affine**（u 的仿射像，末尾可再接一次与常量的 `^ & |`）：把乘数写成 `2^d·奇数`，
  `bit_s` 化为 `bit_{s-d}(μv + β)`，μ 为奇数。
  - s' < 19：不依赖 v19，而 y19 随 v19 翻转，不可能。
  - s' = 20..29：翻转 `v_{s'}` 会翻转该位，而 y19 不变，不可能。
  - s' = 19：是 20 位问题。C 程序对每个奇数 μ（2^19 个）与 g 求 ν 的可行弧，结果
    **没有解**。
  - s' = 30、31：y19 只取决于 v mod 2^20，`v + j·2^20` 仍在定义域，所以输出位在每条
    纤维上不变。由此 s' = 30 不可能，s' = 31 只剩 μ = ±1；此时输出位是 v mod 2^20 的
    单阈值函数，而 `y19 ⊕ g` 在 2^20 个余数上变化 35,586 次，也不可能。
  共 942 个模板。
- 其余单移位模板 1,117 个与多次移位模板 1,566 个，交给完整问题求解。

对其他移位输入，按 s 分宽度用 z3 求这个单比特条件也很慢：`v^K → MAD` 与
`MAD(u) ^ MAD(u)` 在 s = 19、20、25、31 都 60 秒超时，前者连已知解 K = R 都找不到。
所以这两类直接交给完整问题。

**依赖集论证**（`grammar4_round0_audit863.py`，用于超时项）。对模板的每一组移位量，
追踪输出第 0 位可能依赖的输入位：位运算只传本位，算术运算（MAD、`a*K+b`、`a*b+K`）
让第 j 位依赖操作数的第 0..j 位，右移 s 读第 j+s 位，输入第 30、31 位在定义域上为 0。
这是对真实依赖的上估计。y19 依赖第 0..19 位中的每一位：对每个 j < 20 都找到了单比特
翻转 `(v, v ^ 2^j)` 使 y19 改变。若某组移位量下依赖集缺了 0..19 中的某一位，该位的翻转
见证在整个依赖集上相同、y19 却不同，这组移位量不可能。末条若是右移 s ≥ 3，输出只有
至多 2^29 个值，不可能在 2^30 个输入上单射。每组移位量都不可能时，模板被排除。

### 2.4 对照

| 对照 | 结果 |
|---|---|
| C1 换成可吸收常数，`v^K → MAD → >>s → ^` | 264 秒求得 K = R、μ = 4097、ν = C0+2^31、s = 19，并通过 2^30 全域 C 穷举 |
| 同一模板，真实 C1 | 339 秒 UNSAT |
| 仿射 20 位检查：R 低 20 位全 0 | 找到 8 组解，含 μ = 4097、ν = C0 mod 2^20 |
| 仿射 20 位检查：R 低 20 位全 1 | 找到 8 组解，含 μ ≡ −4097 |

## 3. 结论

本轮也没有找到 863。

- **除法扩展**：首段三指令语法加入 `// % cdiv < ==` 后，新增的 14,777 个模板中 14,679 个
  排除，98 个未定，都是“常量除法代替右移”或末条两值相除的形状。
- **第 0 轮并入节点异或**：14,150 个四指令模板中 13,922 个排除，228 个未定。占大头的单移位
  模板由比特 0 引理精确排除：凡移位读的是位运算值或仿射值，都不可能。未定项集中在
  “先对输入做位运算再乘”和多次移位这几类。

两项都没有出现可用的改写。未定项只是在 2 分钟内没判出来，不代表有解。它们也是这两个语法里
最接近现有写法的形状；本轮和此前凡是跑出结果的同类形状，全部是 UNSAT。可执行最好成绩仍是 864 cycles。
