# 除法范围闭合与带存活字的 C5 吸收

**可执行最好成绩仍为 864，尚无 863 程序。** 本轮完成上一轮剩余 127 个
预备除法连接的闭合，并新增 1,899 个不同的中段恢复连接检查。全部抽样连接
已排除；完整四指令语法和整个内核的最优性仍未证明。提交内核没有变化。

## 1. 从 127 个 UNKNOWN 到本批 528 个全部关闭

上一轮在八个真实存活字 `[z,u,v,b,prior,a,a>>19,a XOR C1]` 上抽取了 528 个
四指令连接，每个含一次预备 DIV/REM/CDIV，其他为 MAD/XOR/AND/OR。目标为
原来的 `e=9*z+C4`、fold16、根异或和下一次 MAD4097，共五条。原先排除 401
个，余 127 个；并未提供 e 作为免费输入。

本轮首先让每个输入样本获得一个独立任意 q，仅保留正确的数值范围。
这个模型丢弃除法方程、q 与分子的关系和不同样本之间的函数一致性。
因此它的 UNSAT 足以排除原连接，SAT 本身不能成为候选。

最初范围为 floor q≤2^31-1、ceil q≤2^31、REM q≤9,004,123；后者来自
此前的 478 状态信息证据。随后补证 D=2 的 floor/ceil 也无法把 b16 送到
输出 bit0，于是有效 D≥3，统一 q≤0x55555555。前两次保存的较松范围
UNSAT 仍然有效；没有把旧记录改成新范围。

| 原 127 个的最终新增依据 | 数量 |
|---|---:|
| 独立任意 q 的范围放宽 UNSAT | 113 |
| 两个固定计算旁路的完整逆参数枚举 | 6 |
| 相同分子的具体碰撞 | 3 |
| 缩放旁路的四点差分 | 1 |
| v=0 消去乘数的有限必要条件 | 1 |
| 任意 prior 掩码的四点差分 | 3 |
| 合计 | 127 |

范围搜索原始阶段依次为 103 UNSAT/24 UNKNOWN、10 UNSAT/14 UNKNOWN，
以及更紧范围的 14 UNKNOWN。后面的数学证书独立关闭这些未决；超时原样保留。
因此本批 **528/528 抽样连接**现已排除。此前两个固定除数留下的 110 个分支
也被一般除数证明覆盖，无需把有限除数试验当作一般证明。

## 2. 最后的任意掩码族：混合差分恰为 2^31

最后三种连接实际为：

```text
P = A*b + a_shr19                    # uint32
q = floor(P/D), ceil(P/D), or P%D
h = prior & L
Y = G*q + h                         # uint32
```

A、D、L、G 均是任意根相关预备 uint32 字，D 非零。固定允许的原始根为
`0x12345678`，目标根字为 `0xa76e1971`。取四个 b：

```text
2558187825, 3095059761, 410700081, 947572017
```

对应 prior 为：

```text
1560818648, 2097689560, 3708302296, 4245173208
```

定义 Δf=f3+f0-f1-f2（模 2^32）。prior 的两个轴只分别翻转 bit29、bit31，
所以对**所有掩码 L**都有 Δ(prior & L)=0。b 和 a_shr19 各自 Δ=0，故
对所有 A 都有 ΔP=0。实际冻结目标却有 **ΔY=2^31**。

在 b 与 b XOR65536 的低位见证上，h bit0 不变，目标 bit0 翻转，故 G 必为
奇数。写 B=G^-1 后，Δq=B*ΔY=2^31：

- D≥5 的 floor/ceil：q≤ceil(MASK/5)，混合差分的圆周距离至多 2*qmax，
  严格小于 2^31，矛盾。
- D=1、3：D*Δq=2^31；除法恒等式要求它是四个 0..D-1 余量的有符号混合差分，
  距离至多 2*(D-1)，矛盾。
- D=2、4：P low16 在 b XOR65536 下不变，商 bit0 只读 P low2/low3，
  无法产生要求的输出 bit0 变化。
- REM：478 状态证据界定 D≤9,004,124，q 更小，直接违反同一个距离界。

证书独立检查全部 32 个掩码位的差分，并用符号 L 再证 Δh 恒零；四点均用
真实合法树/输入构造和未改动的冻结参考回放。它关闭这个具体族的完整参数域，
不等于关闭任意计算旁路或任意四指令图。

## 3. 其他闭合证据

三组固定旁路残差另做了 **3×2^31=6,442,450,944** 个奇数逆乘数的完整扫描。
每个都发现至少两个不同的 q>2^31，因而不能成为范围受限的除法结果。其中
两个旁路用于本批六个未决连接；第三个作为独立的 `Y=G*q+h` 结论保留，
没有误算到实际为 `Y=G*h+q` 的连接上。

`b*(a_shr19+1)` 的碰撞输入为 36,240,888 和 1,657,121,264，分子均为
1,191,700,144，但必需的 `Y XOR z` 分别为 3,054,722,935 和 174,328,744。
任何相同预备除数都产生相同 q，后续共同仿射变换无法满足这两个值。

缩放旁路 `h=z OR (z*z+b)` 使用另一组四点，使 Δh=ΔP=0 而目标混合距离
为 1,885,862,032，结合小除数余量和大除数商范围关闭 `Y=G*h+q`。
平方尾部在 512 个 v=0 的合法输入上消去了乘数 A；独立任意 q 仍不能使
`Y=(b*b+q) XOR K` 对共同输出 K 成立。详细数值均在旁路审计 JSON 中。

## 4. 额外存活字与输入编码的 C5 恢复搜索

在已经研究过的 a/prior/任意输入键模型上，本轮新增四指令 C5 吸收目标：

```text
available = [a, prior=(a-C0)/4097, a XOR (a>>19) XOR K]
target = F(a XOR (a>>19) XOR C1) XOR 0xb55afa53
```

原来的 b 和更改键后的字没有同时免费提供。低 11 位必要条件使用合法完整
输入子域 a<2048，此时 a>>19=0，prior 的模逆关系真实保留。低域 UNSAT
排除对应完整程序；低域 SAT 仍须提升、实际构图和调度。

- 首条 MAD 的 63 个顺序各抽 8 个读取 prior 的连接，共 **504 个**。
  首轮 503 UNSAT/1 UNKNOWN，细化后全部排除。
- 两条独立 MAD、位运算、最后仿射 MAD，使用 30 种具体首条形状的无序对，
  共 **1,395 个**。首轮 1,392 UNSAT/3 UNKNOWN；延长后再排除两个。
  最后一项只读 keyed 字，令 x=a XOR K 后归入已有单输入多项式族；本轮重新
  执行该一般输入键必要条件，3.149 秒 UNSAT，并回放其 80 个归一化控制。

两个清单没有交集，共 **1,899 个不同连接**全部关闭。这不是完整四指令语法。

另把混合 a/keyed 仿射双臂的 26 秒查询改写为专用必要条件：通过合法归一化
清除 K、B、D 的最低/最高位及 A 最高位，再把最后 G/H 换成奇数逆系数。
同一完整低域族在约 0.53 秒 UNSAT。输出键始终按目标固定为 PRE_C5，没有
额外钉住待综合的系数。两位字长的全部参数、随机较宽函数、自动正向控制及真实 live 投影
分别核对这些归一化；它不声称在含 a>>19 的任意完整输入上直接套用同一归一化。
