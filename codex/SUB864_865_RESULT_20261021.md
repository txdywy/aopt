# Verified 865-cycle result

The active `perf_takehome.py` executes **865 cycles**, improving the preserved
866 result by one cycle. The goal of **863 or fewer remains open**. This is
a locally verified score, not a claim of global optimality or browser
submission acceptance.

The kernel specializes height 10, 2047 nodes, 256 zero-initialized indices
and 16 rounds, under the Without Indices / final-values-only contract.

## Mechanism

The signed-parity, stride-four tree-record algorithm remains the same.
The image uses the consumed input region `[2310,2534)` with
X=(-72,-52), Y=(2266,2378), V=(-4,4), and one anchor bank.

Three-word FLOW broadcasts replace selected four-word scalar-copy blocks.
Two scalar copies and the original source form a three-word block. One
vector select uses two views shifted by three words and a known `11100000`
mask. A contiguous eight-word result view combines the original block with
five result words. The instruction still writes its full eight-word
architectural destination; padding is included in all allocation/bounds
checks. Other constants and cache vectors use STORE/reload broadcasts.
An early native broadcast of 3925396509 preserves startup utilization.

The decisive scheduling change is an optional positive scalar priority bias
in `packet_mode_search.cpp`. With bias 2, native vector instructions precede
otherwise similarly prioritized scalar instructions that could themselves
merge into vectors. This changes resource allocation and dependency timing.
Seed 1163 first found 865 at iteration 579 of a 1200-iteration search. Both
the saved solution and its complete lowered instruction stream were checked
independently of the search heuristic.

Lower-arithmetic shared-layout alternatives reached 51669 lanes but still
took 866 cycles. Their startup and memory dependencies consumed the savings.
They remain separate experiments in `SUB864_RESEARCH_20261021.md`.

## Exact reproduction

Only Python's standard library and the original problem module are needed
for the active standalone file:

```bash
python3.12 tests/submission_tests.py
python3.12 -m codex.verify_compact
```

Rebuild the exact program from readable compiler sources and the saved
calendar, without repeating the search:

```bash
python3.12 -m codex.research_bootstrap864 --prefix /tmp/aopt-865 --layout tight --thirds --native-c2 --small-stage= --sink 0 --literals 0 --literal-flow 2
python3.12 -m codex.packet_modes export --ir /tmp/aopt-865.ir.pkl --prefix /tmp/aopt-865-modes
cp codex/stride4_865_schedule.txt /tmp/aopt-865-modes.sol
python3.12 -m codex.packet_modes check --prefix /tmp/aopt-865-modes
python3.12 -m codex.emit_packet_submission /tmp/aopt-865-modes.json /tmp/aopt-865.py --cycles 865
```

## Sources and remaining work

Record-family ideas were informed by [Josu San Martin's public research
log](https://github.com/josusanmartin/josusanmartin.github.io/blob/master/vliw/chat.log).
The preserved [Sakauma 880 kernel](https://github.com/Sakauma/my_original_performance_takehome/blob/cb2e0554735ef7d0dfde1a04bc2c12c4bb2ed38d/perf_takehome.py)
supplied initial hash scheduling priorities. The new compiler, three-word
broadcast lowering, allocator and schedule were implemented locally. The
original Anthropic notice is retained in the standalone source.

The original [leaderboard](https://vliw-challenge.fly.dev/) was checked on
2026-10-21 and still showed six tied 864 entries under Without Indices. No
new publicly reproducible sub-864 implementation was found in this pass.

With the usual 52-lane startup and 116-lane drain allowances, the active
51707-lane graph needs at least 865 cycles. Reaching 864 within this family
requires at least 35 fewer arithmetic lanes; reaching 863 requires at least
95 fewer. These conditional bounds are not global optimality proofs.
