# 863 继续探索：哈希的编码刚性与 C1 的不可吸收性（2026-10-27）

**可执行最好成绩仍为 864 cycles，本轮没有得到 863 程序。**

## 1. 哪些常数能被“免费”吸收

每轮哈希（C5 已并入节点）为

```text
x --MAD0--> a --(a>>19, ^C1, ^)--> y --F: MAD,MAD,^,MAD--> e --(e>>16, ^)--> s --(^n')--> 下一轮 x
```

相邻两步之间，生产者能免费改写输出，消费者能免费吸收输入，两者的交集才是
真正免费的编码：

| 边界 | 生产者可给出 | 消费者可吸收 | 交集 |
|---|---|---|---|
| a（MAD0 → g19） | 任意仿射像 `μa+ν` | 只吸收经 g19 线性传递的异或常数 | 仿射兼容的异或常数 |
| y（stage 1 → F） | 末条是异或：任意异或常数 | F 的两个 MAD：任意奇数仿射像 | 仿射兼容的异或常数 |
| e（F → g16） | MAD：任意仿射像 | 异或常数（经 g16 推入节点） | 仿射兼容的异或常数 |
| x、s（节点异或两侧） | — | 任意异或常数（并入预异或节点） | 任意异或常数 |

“仿射兼容的异或常数”是满足 `t XOR K` 恰为模 2^32 仿射映射的 K，只有
`0, 2^31, 2^32−1, 2^31−1` 四个。在 y 处，把 a 端的四个常数经 g19 映射后，与 y
端四个常数逐对异或，得到的免费集合恰好 16 个：

```text
0x0 0xfff 0x1000 0x1fff 0x7fffe000 0x7fffefff 0x7ffff000 0x7fffffff
0x80000000 0x80000fff 0x80001000 0x80001fff 0xffffe000 0xffffefff 0xfffff000 0xffffffff
```

`C1 = 0xc761c23c` 不在其中。C0、K1、K2、C4 是乘加的加数，C5 并入节点预异或，
都能免费吸收；**C1 是整个哈希中唯一不能吸收的常数**，每轮固定多一条异或，
全程 4,096 lane。

## 2. 两端任意仿射重编码也不能吸收 C1

上表只考虑异或常数。更一般地，若存在奇数 μ、m 及任意 ν、c 使

```text
m * g19(μ*a + ν) + c == g19(a) XOR C1      对所有 uint32 a
```

则 MAD0 改发 `μa+ν`、F 的两个 MAD 吸收 `m·y+c`，stage 1 只剩移位与异或。
`affine_reencode_c1_863.py` 用完整 32 位 bit-blast→SAT 的 CEGIS 求解：

- 目标：16 个样本即 **UNSAT**（49.6 秒）。样本子集无解即推出全体输入无解。
- 阳性对照：把 C1 换成 `g19(2^31)`，一轮即得 `μ=1, ν=2^31, m=1, c=0`，并在
  20 万个随机输入上核验。

`affine_reencode_family863.py` 把 stage 1 推广为两指令形式，s 取 1..31：

```text
xor 族：P(w) = w XOR (w >> s)
add 族：P(w) = w + k*(w >> s)     （覆盖 MAD(t,k,w)、MAD(w,k,t)、w−t）
```

要求 `m*P(μa+ν)+c == g19(a) XOR C1`。**62 个查询全部 UNSAT**（多数 0.02 秒，
add 族 s=19..23 用 0.6–54 秒）。xor 族阳性对照即时得解。add 族对照在五个未知数
全放开时 300 秒未解出，但固定 `μ,ν,m,c` 后瞬间得 `k=3`，只固定 `m,c` 时
0.37 秒得 `k=3`，说明编码正确，只是求解器在两个未知数相乘时较慢；这不影响
UNSAT 的有效性。

## 3. 节点异或也不能并入相邻乘加

若下一轮 x 改为 `x' = m·x + c`（MAD0 可吸收），需要两条指令从 `e'`（F 末条
任意仿射像）和每节点预计算值 `n''` 得到 `m·(g16(e) XOR n') + c`。两条指令
要合入三个量（e、移位结果、节点），唯一的三输入指令是乘加，其结果对节点是
加法可分或乘法耦合；而异或除第 31 位外不是加法可分的。故不可能。

## 4. 结论

哈希中只有四类常数能“免费”移动，C1 不在其列；本轮在两端任意仿射重编码下，
对 stage 1 的 63 种两指令形式（含原始 g19）都给出了完整 32 位 UNSAT。这从结构上
解释了每轮 10 条哈希指令为何无法再压：节点异或与 C1 异或都不能并入乘加。
